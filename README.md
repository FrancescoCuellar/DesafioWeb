# Dulceria EL Norteño
Sitio web y aplicación para Dulcería El Norteño, una MYPE dedicada a la elaboración y venta de dulces tradicionales en la región Lambayeque.
## Descripción del proyecto
Propuesta web enfocada en presentar el catálogo de productos tradicionales, facilitar la gestión de pedidos y ofrecer un canal de contacto/consulta accesible y adaptable a distintos dispositivos.
